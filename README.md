# Panelize CN · AI 对比台

一次提问，同时查看多个 AI 的回答；核对原文后，对比不同观点并生成综合回答。

这是基于 [Manho/Panelize](https://github.com/Manho/Panelize) 的中文改进版，基线提交 `fb9cc70d4c38bf13a5ebb7bf4b76abad107ce2c1`。不是上游官方发布，也不是从零开发的独立产品。原作者 Xiaolai、Wenhao 的版权与 MIT 许可完整保留。

## 安装

1. 从本仓库 [Releases](https://github.com/dstmg/Panelize-CN/releases) 下载安装 ZIP 并解压到固定目录。也可下载本仓库源码 ZIP 后解压。
2. 在 EGO、Chrome 或 Edge 中打开扩展管理页，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 打开 AI 对比台，分别登录需要使用的平台。登录由对应网站处理。

升级时先在设置页导出数据备份，再把新版文件放回原安装目录并重新加载扩展。保持原安装目录有助于保留扩展 ID 和本地数据。新浏览器、新用户环境的登录需要单独完成。

## 主要功能

| 功能 | 说明 |
|---|---|
| 多 AI 同屏 | 沿用上游的多面板、统一输入、截图分享等功能 |
| 国内平台优先 | 优先展示国内常用平台；新增和关闭后记住面板选择 |
| 选择参与平台 | 独立勾选填入/发送对象，显示逐平台结果；不确定时不自动重发 |
| 回答对比 | 预览并修正候选回答，选择分析 AI，确认后才发送分析请求 |
| 逐模型差异 | 按模型编号列出不同主张与独有补充，原文引用可展开，最后综合回答 |
| 我的收藏 | 自定义提示词、编辑删除搜索、使用 `{主题}` 占位符 |
| 本地对比记录 | 手动保存、查看删除，备份导入时合并去重；最多100条 |
| 导出分享 | Markdown、摘要 PNG、设置与收藏及对比记录备份 |

首次启动默认 DeepSeek、豆包，后续可自行添加 Kimi、千问等平台。平台和布局可调整。

## 怎样使用回答对比

1. 各平台回答完成后点击顶部“回答对比”。
2. 检查各平台候选原文是否完整、是否为同一问题；可手动修改或粘贴。
3. 填写原问题，可选择对比角度和关注点。
4. 预览完整指令，确认要交给哪家 AI。确认后，该平台的当前聊天会新增分析请求。
5. 查看每个模型的不同内容、展开引用核对，阅读最后综合回答。可保存或导出。

“无需额外 API Key”指直接使用已登录的网页服务；不代表对应平台、模型或套餐永久免费。分析会把所选回答发送给你选择的 AI 网站。

## 事实与使用边界

- 当前候选采集主要适配文本。图片、附件、复杂公式可能无法完整读取；网站升级可能导致采集或发送失效。
- 一家 AI 的归纳不是客观裁判。引用匹配只证明文字在所选原文中出现，不能证明结论正确。多数模型同意也可能出错。
- 样本中的计算、行业判断、测试周期、提升阈值需要人工核对。不同模型结果也会受模式、搜索和时间影响。
- 单份原文上限40000字符，总上限100000字符；超过限制需手动缩减。分析自动等待最多120秒，可稍后手动读取或粘贴结果。
- 本地记录包含原问题、原文和分析结果。共享电脑和分享导出文件前请检查内容。卸载扩展或清除其数据可能丢失收藏与记录。
- 原始上游资料留在 [upstream](upstream/)，其中安装包、商店、更新和隐私描述仅代表原版，中文版以本页与 [隐私说明](PRIVACY.md) 为准。

## 验证范围

在 EGO 中已验证四个平台候选回答采集；收藏新增、编辑、删除、刷新后读取与变量填写；对比结果保存和刷新后查看。真实 DeepSeek 分析已成功恢复并显示四模型差异及综合回答，同时修复未转义引用引号导致的解析失败。

模拟流程验证过目标平台选择、确认后发送、草稿保护和导出；不等于所有网站和模型都完成真实联发验收。完整备份导出、导入恢复在 EGO 的端到端验收尚未完成。电脑完全重启后的记录恢复也尚未专门验收。

## 开发与打包

需要 Node.js/npm；打包脚本需要 Python 3。

```sh
npm ci
npm test
python scripts/package.py
```

安装包生成在 `dist/`，只包含扩展运行文件、许可和说明，不含开发依赖、测试备份或聊天数据。

遇到问题请在 [Issues](https://github.com/dstmg/Panelize-CN/issues) 提供浏览器版本、平台名称、操作步骤和已遮盖隐私的截图。
